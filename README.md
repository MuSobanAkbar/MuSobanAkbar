I build AI systems that are meant to run in production: tested with evals, protected by guardrails written in code, and watched with logs, metrics and traces.

**Now:** building [torque](https://github.com/MuSobanAkbar/torque), an AI that turns mechanic shorthand into a priced quote, and can't invent a price.

<summary><b>How I build</b></summary>
<br />

- **AI reads and writes; code handles anything that must be exactly right.** Prices, totals and safety rules never come from a model.
- **Measure before shipping.** Every AI feature gets an eval set, with separate gates for the failures that matter.
- **Plan for failure.** Timeouts, clean errors, and no private data in logs.
- **Write it down.** Design docs, decision records and honest "known limitations" in every README.
